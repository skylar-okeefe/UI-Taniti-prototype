## Project Overview
This website is a user interface prototype for the Island of Taniti, designed to provide tourists with essential travel information, lodging options, island transportation, local dining, and booking requests.

## Project Structure
- `index.html` - Home page highlighting main island attractions and navigation
- `lodging.html` - Details on hotels, resorts, and local accommodations
- `transportation.html` - Information on flights, buses, taxis, and vehicle rentals
- `explore.html` - Island sightseeing, entertainment, and local dining options
- `booking.html` - Reservation inquiry form and essential traveler guidance (currency, safety, healthcare, electrical requirements)
- `CSS/styles.css` - Custom styling and layout sheets
- `IMAGES/` - Visual assets used across the prototype
